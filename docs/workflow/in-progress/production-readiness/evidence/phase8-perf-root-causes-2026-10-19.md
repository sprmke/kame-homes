## Host login CLS 0.25 (phone) / 0.10 (desktop)

`PerformanceObserver` layout-shift sources: the sign-in card (`max-w-[420px]`) grows 71px ~2.5s after load when a 65px Turnstile challenge is inserted. Turnstile is `appearance: interaction-only`; the visible challenge appears because headless Chromium (Lighthouse, Playwright) is scored as suspicious. Most real visitors pass invisibly. **Not a code defect**; confirm with real-user web vitals in PostHog once keys are live (PR-112 downgraded to 🟡).

## 4. Edge — Sentry

`_shared/sentry.ts`: envelope POST, DSN parse + memo, 3 s timeout, `environment`,
`fn` / `request_id` tags, sanitized `extra`. Missing: `release`, `user.id`, org/property
tags, fingerprinting, `level` other than `error`, message capture for warnings, cron
check-ins, provider tags, per-isolate dedupe / rate cap, trace linking (F-04, F-05).

## 7. What is already good (do not redo)

- Typed catalog + single capture helper on each side; denylist sanitizers with tests.
- Identify / reset, guest email omitted, groups for org / property / parking.
- `sanitizeUrlForTelemetry` on edge; browser Sentry URL already stripped to origin + path.
- Central `handleEdgeError` with `EdgeError`, deliberate-4xx skip, structured `logEvent`,
  `requestId` on 5xx bodies.
- `get-health` liveness endpoint (uptime monitor target).
- `/ingest` first-party rewrite for PostHog.
- Source-map upload failure never fails the build (pattern reused for Sentry).
- `_shared/backgroundTask.ts` exists for off-response work.

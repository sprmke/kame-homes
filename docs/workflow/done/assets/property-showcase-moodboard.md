## Shared takeaways

1. **Hero = one job** — brand/property name, one line, one CTA, full-bleed media.
2. **Nav is template-owned** — scroll-spy anchors, not marketing shell.
3. **Motion earns its keep** — parallax / pin / stagger only when it clarifies hierarchy.
4. **Images carry trust** — property media only (v1); no stock filler.
